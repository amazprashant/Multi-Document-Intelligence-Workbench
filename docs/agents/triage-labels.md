# Triage labels
| Label | Meaning |
|---|---|
| `bug` | Behaviour contradicts `ARCHITECTURE.md`/`QUESTIONS.md` |
| `feature` | New capability; needs acceptance criteria |
| `provenance` | Anything affecting evidence, quotes, verification (high priority) |
| `security` | Upload handling, validation, secrets, prompt injection (high priority) |
| `llm-quality` | Wrong/missed findings with a real model; attach the documents (synthetic only) |
| `docs` | Documentation only |
| `good-first-issue` | Small, well-scoped |
| `needs-info` | Cannot reproduce / missing sample |
Priority: `P0` data leak or false-verified evidence · `P1` wrong findings · `P2` UX · `P3` polish.
